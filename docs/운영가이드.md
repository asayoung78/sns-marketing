# 부산온나우 운영 가이드 (반자동)

## 한눈에 보기
| 언제 | 무엇이 오나요 (텔레그램) | 할 일 |
|---|---|---|
| 매주 월 07:00 | 📅 다음 2주 **릴스 기획표** (게시일·행사·촬영 추천 시간·찍을 장면) | 촬영 일정 잡기 |
| 릴스 게시 3일 전 | 🎬 **릴스 초안** 링크 | 영상 올리기 → 초안 다듬기 → 댓글 `승인` |
| 뉴스 게시 전날 20:00 (일·화·목) | 📰 **뉴스 카드 초안** 링크 | 확인·수정 → 댓글 `승인` |
| 릴스 게시 당일 15:00 | ⏰ 영상 없음/승인 전 안내 | 필요하면 승인 |
| 게시 시간 (릴스 19:20 / 뉴스 08:00) | ✅ 게시 완료 | — |

**승인하지 않은 초안은 절대 올라가지 않아요.**

## 1. 영상 올리기 (구글 드라이브)
- 폴더: `부산온나우_영상`
- 파일 이름 앞에 **초안 번호 + 밑줄**: 예) 초안 #12 → `12_부산포.mp4`
- 세로 촬영, 15~45초 (45초가 넘으면 앞부분 45초만 사용)
- 영상이 없으면 공식 포스터·사진으로 **사진 슬라이드 릴스(18초)**가 자동으로 만들어져요.

## 2. 사진 올리기
- 초안 글 아래 **댓글에 사진 첨부** → 슬라이드 맨 앞에 들어가요 (GitHub 앱에서 가능).

## 3. 초안 다듬기
초안 글 오른쪽 위 `⋯` → **Edit**에서 아래 칸을 자유롭게 고치세요.
| 칸 | 쓰이는 곳 |
|---|---|
| 큰 제목 (2줄) | 릴스 첫 화면 / 카드 표지 |
| 자막 | 릴스에 한 줄씩 차례로 |
| 인스타 본문 | 게시물 설명(캡션) |
| 카드 1~3, 마무리 문구 (뉴스) | 카드 내용 |
| 조사 자료 | 참고용 — **확인 필요** 항목을 채워 주세요 |

⚠️ 맨 아래 `⚠️ 아래 숨은 줄은…` 이후는 지우지 마세요.

## 4. 댓글 명령
| 댓글 | 하는 일 | 비용 |
|---|---|---|
| `미리보기` | 지금 내용으로 릴스·카드를 다시 만들어 링크를 남김 | 0원 |
| `승인` | 예정 시간에 게시 | 게시 시 0원 |
| `승인 취소` | 승인 취소 | 0원 |
| `건너뛰기` | 이번 초안은 올리지 않음 | 0원 |
| `지금 게시` | 바로 게시 | 0원 |
| `교체` | 다른 행사로 릴스 초안 다시 만들기 | AI 비용 |

※ AI 비용은 **초안을 처음 만들 때**와 `교체`에서만 들어요.

## 5. 설정 바꾸기 (`settings.toml`)
- 자동화 켜기/끄기: `[schedule] enabled`
- 릴스 시작일·간격·시간, 뉴스 요일·시간, 기획표 요일: `[schedule]`
- 릴스 길이: `[reels]`
- 배경음악: 드라이브 `부산온나우_영상/음악` 폴더에 mp3 넣기 (돌아가며 사용)

## 6. 문제가 생기면
- 텔레그램 ⚠️ 알림 + 초안에 `오류` 라벨 → 초안 댓글의 오류 내용을 캡처해서 Claude에게 보내 주세요.
- 연결 점검(무료): Actions → **공공데이터 API 설정 점검** → Run workflow
